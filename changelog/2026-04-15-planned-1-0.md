What we're targeting for the OfficeOS 1.0 general availability release.

## Core platform

- **Agent lifecycle management** — create, configure, start, stop, and delete agents from the dashboard
- **Provider registry** — connect LLM providers (OpenAI, Anthropic, Google, etc.) with encrypted credential storage
- **Skill execution engine** — first-party TypeScript skills running in the skill-runtime, invoked by agents via GraphQL
- **Agent personality vault** — per-agent CouchDB vault for SOUL.md, IDENTITY.md, and AGENTS.md personality files
- **Session history** — full conversation history stored in Postgres, viewable in the dashboard
- **Single-tenant Kubernetes deployment** — self-hosted, one cluster per customer, no shared infrastructure

## Skills shipping in 1.0

- Google Calendar — read, create, update events
- Gmail — read, search, send, draft emails
- Google Drive — list, read, search files
- Linear — manage issues, projects, cycles
- Notion — query and update pages and databases
- Slack notifications — post messages to channels (via skill, not channel integration)
- Web search — search the web and fetch page content

## Compliance and legal

- **Terms of service and privacy policy** — published at officeos.co
- **Data residency** — all data stays in the customer's cluster, never leaves
- **Audit logging** — all agent actions logged with timestamps and session IDs
- **Credential encryption** — all provider API keys encrypted at rest with AES-256

## Not in 1.0

- Multi-tenant / SaaS hosted offering
- Mobile app
- Agent-to-agent communication
- Real-time streaming responses in dashboard
- Custom skill upload and marketplace
