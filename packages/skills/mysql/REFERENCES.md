## API Coverage
- Connection management (connect with SSL/TLS support)
- Query execution (parameterized queries, single-row queries)
- Schema inspection (databases, tables, columns, indexes)
- Table DDL (create, drop, alter)
- Data manipulation (insert, update, delete, upsert via ON DUPLICATE KEY UPDATE)
- Transaction management (begin, commit, rollback)
- Server diagnostics (table info, database size, active connections, process list)
- Data export (CSV and JSON)
- User management (list users, create user, grant privileges)
