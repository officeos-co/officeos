## API Coverage
- Spreadsheets: create, get metadata, list sheets
- Read: get values, batch get values
- Write: update values, append values, batch update values
- Clear: clear values, batch clear values
- Sheets (tabs): add, delete, rename, duplicate
- Format: format cells, auto resize columns, merge cells, unmerge cells
- Sort/Filter: sort range, add filter, remove filter
