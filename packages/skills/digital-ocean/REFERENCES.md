# References

## Source SDK/CLI
- **Repository**: [digitalocean/doctl](https://github.com/digitalocean/doctl)
- **License**: Apache-2.0
- **npm package**: `dots-wrapper` (community), or direct REST API usage
- **Documentation**: [https://docs.digitalocean.com/reference/api](https://docs.digitalocean.com/reference/api)

## API Coverage
- **Droplets**: list/get/create/delete droplets, power on/off, reboot, resize, snapshot
- **Databases**: list/get/create/delete database clusters, list/create connection pools, list DB users
- **Domains**: list/get/create/delete domains, list/create/update/delete DNS records
- **Kubernetes**: list/get/create/delete clusters, get kubeconfig, list node pools
- **Spaces (S3-compatible)**: list/create/delete spaces, list/put/get/delete objects
- **Networking**: list/create firewalls, list/create load balancers, list floating IPs
- **Apps**: list/get/create/delete apps, list deployments
- **Account**: get account info, list/add SSH keys, list regions, list sizes, list images
