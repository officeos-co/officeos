# Jenkins

Manage Jenkins jobs, builds, queue, nodes, and views via the Jenkins REST API with Basic auth.

## Categories

- Developer Tools

## Credentials

| Key | Label | Kind |
|-----|-------|------|
| `url` | Jenkins URL | text |
| `user` | Username | text |
| `api_token` | API Token | password |

## Installation

This skill is included in [EnterpriseAgentOS](https://officeos.co) and requires no separate installation.
