## API Coverage
- Status: working tree status, unstaged diff, staged diff
- Commits: log, show, commit (with amend support)
- Branches: list, create, delete, switch, rename, merge, rebase
- Staging: add, reset, restore
- Remote: list remotes, add remote, fetch, pull, push, clone
- Stash: stash, pop, list, drop, apply
- Tags: list, create, delete, push
- Blame: file line annotation with range support
- Cherry-pick: apply commits across branches
- Conflict resolution: list conflicts, resolve (ours/theirs/manual)
- Config: get and set config values (local/global)
- Clean: remove untracked files and directories (with dry-run)
