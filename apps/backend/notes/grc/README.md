## Structure

- `skills/` contains the actual skill packages. Each folder has a `SKILL.md` file and optional `references/` documents.
- `source-readmes/` contains copied repository README and installation/marketing docs. These are not executable skill definitions.
- `evaluations/` contains the copied evaluation response corpus. These files are useful for comparison and examples, but they are not skill packages.
